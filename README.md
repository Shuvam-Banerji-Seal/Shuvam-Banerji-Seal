## Overview

I am a BS-MS student at IISER Kolkata (Chemistry major, Computer Science minor), building systems at the intersection of computational chemistry, information retrieval, and AI engineering.

Current focus areas:
- Verifiable retrieval-augmented generation and information retrieval for scientific domains
- Computational chemistry workflows and molecular simulation tooling
- Agentic AI systems and data pipelines for research and startup products

Recent outcomes:
- ECIR 2026 accepted: AgriIR (domain-specific retrieval framework)
- FIRE 2025 accepted: Hierarchical opinion classification with LLMs
- TREC 2024 paper: query reformulation and layered retrieval
- Co-founder: Synapse (AI-fintech) and UnderWater AI (deeptech), both MeitY GENESIS funded

## Mini Games (Markdown + SVG)

### 1) Gradient Descent Guess
Use the curve below and guess where convergence is likely the fastest.

![Gradient Descent Game Board](assets/svg/gradient-descent-landscape.svg)

Options:
- A: very early high-loss region
- B: mid-path around first valley
- C: near stable minimum basin

<details>
  <summary>Answer</summary>
  C is usually best for final convergence stability; B can be useful for faster exploration.
</details>

### 2) Neural Path Maze
Start from `Input` and choose your route:
- Route A: Input -> Dense -> Dense -> Output
- Route B: Input -> Attention -> Retrieval -> Output
- Route C: Input -> Random Jump -> Output

![Neural Maze Board](assets/svg/neural-network-pulse.svg)

<details>
  <summary>Scoring Guide</summary>
  Route B scores highest for your profile because it reflects retrieval-augmented and transformer-based work.
</details>

### 3) Molecular Stability Challenge
Inspect orbital and docking animations and pick the stronger stability signal:
- Option A: symmetric orbital behavior with smooth transitions
- Option B: abrupt oscillations and fragmented motion

![Orbital Challenge](assets/svg/chem-orbital-spin.svg)
![Docking Challenge](assets/svg/molecular-docking-wave.svg)

<details>
  <summary>Answer</summary>
  Option A generally indicates a more stable pattern under this simplified visual heuristic.
</details>
